## About the Project

This is a business landing page created using only HTML and CSS. The project focuses on presenting a business service website with a clean layout, service sections, work showcase, and contact/lead generation areas.

The purpose of this project was to practice building a professional multi-section webpage using HTML structure and CSS styling. It helped me improve my understanding of layout design, section spacing, typography, buttons, cards, forms, and responsive-looking webpage structure.

---

## Project Overview

The website is designed as a marketing/business website. It includes a hero section, service information, an about section, a step-by-step approach section, a project/work showcase, and a contact form area.

The main goal of this project was to practice creating a complete business-style landing page with clear sections and a polished visual structure.

## Installation & Setup

To run this project locally:

1. Clone the repository:

```bash
git clone https://github.com/shirsendu-dev/Business-website.git
```

2. Go to the project folder:

```bash
cd Business-website
```

3. Open the `index.html` file in your browser.

You can also use the **Live Server** extension in VS Code for a smoother development experience.
